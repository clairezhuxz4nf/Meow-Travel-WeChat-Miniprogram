# 喵游视觉设计规范

## 定位

喵游是通用的多目的地旅行管理产品，不绑定欧洲或其他特定区域。视觉原则是“安静的界面，鲜活的旅途”：地图 API、地点实拍图和用户内容承担主要视觉表达，UI 保持克制、清晰和可靠。

## 核心色

| Token | 色值 | 用途 |
| --- | --- | --- |
| Background | `#F7F4EE` | 页面暖白背景 |
| Surface | `#FFFCF7` | 卡片与弹层 |
| Surface Muted | `#E9E5DE` | 次级区域 |
| Ink | `#2E3130` | 主文字与线条 |
| Secondary Ink | `#686A67` | 辅助文字 |
| Line | `#D8D3CB` | 边框与分割线 |
| Fog Blue | `#A9BCC8` | 交通、次按钮 |
| Sage | `#A8B39B` | 确认、住宿 |
| Dusty Rose | `#D6A6A0` | 共享、柔和提醒 |
| Muted Ochre | `#C9A65B` | 票券、手绘高亮 |
| Coral | `#D96A60` | 主操作与当前路线 |

色彩比例建议为 70% 中性浅色、20% 文字和边框、10% 强调色。单屏显著强调色不超过两种。

## 排版与空间

- 系统字体优先：PingFang SC、Noto Sans CJK SC、Microsoft YaHei
- 页面左右边距：16 px
- 模块间距：24 px
- 卡片间距：12 px
- 卡片内边距：16 px
- 主卡片圆角：16 px
- 普通卡片和照片圆角：12 px
- 触控区域不小于 44 × 44 px

## 地图与照片

- 地图使用中性道路、浅绿公园和浅蓝水域，不叠加全屏品牌色。
- 默认 Pin 使用暖白底和炭黑轮廓；选中态使用珊瑚色中心。
- 地点照片保持自然色彩，不使用统一高饱和滤镜。
- 图片上的文字放在暖白半透明承载层中。

## 猫咪旅行搭子

猫咪是品牌辅助角色，只用于空状态、完成反馈、友好提醒和品牌页。地图中心、金额、二维码和确认码附近不放置角色；同屏完整猫咪不超过两个。
